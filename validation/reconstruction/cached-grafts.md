# Cached digit grafts

The existing closed digit store now supports a whole guarded graft. Its actual
counter bounds every original artifact use. A shared-artifact lookup establishes
that the old boundary exists; the bound supplies a fresh one-coordinate prefix.
The operation checks the imported environment and only the old lookups needed
for shared binding compatibility, then inserts every renamed imported row into
the same index. It does not reconstruct or scan the whole old environment.

Generic batch insertion has complete original merge and rename equations for
all injective key encodings. Original readiness and whole-graft bound theorems
prove formation and the updated strict bound. The typed operation reuses the
existing store's invariant. Its complete optional result retains the actual
counter and every original relation. Missing preparation has no result row;
a rejected operation on a prepared state has one explicit absent-result row.

This API reserves its stored prefix and advances the counter after every
successful graft. That reservation policy is explicit operation state. Other
proved fresh embeddings remain valid graft constructions; this comparison
retains the particular prefix selected by the supplied state. It does not
require the stored bound to equal a minimal bound recomputed from the material.

Fourteen actual methods run on twenty-seven cases. Both the typed operation
and complete original reference have all-input equality theorems and are
selected and adequate. All twenty-two original source cases are directly
preserved, with the correspondence's scope computed natively. Controls omit
shared-artifact or binding guards, discard imported bindings, change the head,
conflate unavailable preparation, insert unchecked material, recompute a
minimal prefix, refuse results or retain the old state.

Persistent histories after zero, 32 and 128 growing grafts retain 1, 33 and 129
artifacts and next heads 1, 33 and 129. Three grafts that only reintroduce the
shared boundary leave one artifact and advance the head to 4. The next actual
graft allocates at Some [4]; recomputing the minimal prefix produces Some [1].
Both displayed environments are formed, but their complete results differ.
Matching shared bindings are admitted, the conflicting boundary is refused,
and malformed old preparation remains distinct from a failed new operation.
