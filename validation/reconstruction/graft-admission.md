# Original guarded graft admission

Original readiness requires formation of both environments, an identical artifact
at the old shared use and imported boundary, a complete fresh embedding and
compatibility of all shared bindings. The general graft theorem derives whole
result formation from these prerequisites. Under the same embedding, complete
merge formation is equivalent to the remaining binding compatibility condition.

The finite compact guard computes these conditions from complete actual inputs.
Its exact original optional result relation preserves every original and renamed
row on success and explicitly refuses a failed graft. Thirteen actual methods
run on twenty-two cases. The direct boundary check and complete-merge formation
alternative are selected and adequate; both have all-input equality theorems.
Controls omit prerequisites, require passive boundaries, drop bindings, retain
only the old environment, change the constructor, add unsupported rows or omit
successful or refused result rows.

All sixteen preceding complete subjects and raw compact grafts are recovered
unchanged. The conflicting boundary refuses while retaining its unformed raw
merge as an observation. Matching existing shared bindings are admitted. Empty
or missing shared sources refuse even where the raw merge is formed. Malformed
old environments, imported artifacts, source slots and target uses remain
separate failed prerequisites. Output formation alone does not authorize them.
