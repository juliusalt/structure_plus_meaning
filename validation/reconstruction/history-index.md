# Indexed history admission members

The original required-history step admits a requested predecessor only when
its complete site and generation value occur in the ordered admission ledger.
The new closed history state retains that entire original state and an index
whose decoded relation equals every ledger member. Repeated ledger rows retain
their original order and multiplicity; the membership index presents their
set relation without replacing the ledger.

Initialization indexes the complete existing ledger once. A step looks up each
requested site and generation, then executes the original replay and policy
attempt. Success appends the same new ledger row and inserts that row into the
persistent index. Generic encoded site relations supply exact lookup and
insertion contracts for the complete optional-use and address boundary.

The original attempt and append operations are factored from the existing
step. Every typed optional result projects to the whole original resulting
state and the exact full ledger relation. This includes every original source,
requirement, policy, material and ledger field. The original operation defines
the reference independently of the cache. Fourteen methods run on sixteen
cases, with all twelve preceding history subjects recovered exactly.

Both the typed method and original reference are selected and adequate.
Controls expose stale or empty caches, lost previous or new ledger rows,
reordered ledgers, unsupported index entries, altered requirements, a no-op,
refusal, an empty output family and conflated unavailable input. A stale cache
preserves the complete immediate original state but fails complete-result
equality. Comparing only that original-state projection would miss the error.

One formed fixture retains four artifacts and three bindings but has an empty
ledger. The original and indexed steps refuse its requested predecessor;
omitting the membership gate admits it. This fixture distinguishes material
reading from admission. Its reachability is not asserted. Actual subsequent
steps retain growing ordered ledgers of two through five members, complete
indexes, and material up to twenty artifacts and twenty-five bindings.
