# Reconstruct complete native graphs

The original problem is constructing a fresh native realization of a complete
finite rooted graph. Its input retains the entire environment, every original
node and indexed discharge, and the root. Availability requires a formed
environment, a formed graph and all source metadata at its original positions.

The constructor assigns every original node a distinct fresh artifact root.
It compiles every node through the existing proof-node compiler, installs all
artifacts before their reference families, and preserves every old artifact
and outgoing binding. Its result retains the complete correspondence, native
root and graph. The existing native reader recovers that whole graph.

The original abstract graph construction and the finite compiler instantiate
one shared rooted code-family argument. Fixed-coordinate projections also
serve the earlier program installer. A shared finite relation lookup serves
both interface recovery and graph-node compilation. Complete function-graph
and indexed-relation-image laws connect the supplied correspondence to its
original structural subjects.

Six independent conditions inspect each actual result:

1. The returned environment is formed and its native reader recovers the graph.
2. A complete functional map preserves the original root, all node metadata and
   every indexed discharge.
3. The entire original environment and its old readings are preserved.
4. Every returned graph-node use is fresh relative to the original environment.
5. The correspondence is injective on the original nodes.
6. Unavailable original prerequisites produce no result.

The first five require a result when the original prerequisites hold. The
mapping condition permits arbitrary placements; injectivity remains separate
from metadata preservation. The complete constructor satisfies all six
conditions universally. Candidate and workload indices identify actual
operations and complete inputs, with an exact original-subject observation
equation and a complete shared report equation.
