# Reconstruct actual source checks and package extensions

The independently stated condition is that the complete proposed source is
the native package readable at the actual environment, use and root. The
source program includes every interface and complete keyed clause, with all
binders, premise sockets, callees, literal targets and material operands.
Equality of its definition domain alone cannot establish that condition.

`Factor_Finite_Source_Observations` derives each finite observation from those
complete inputs and proves its equation against the original `native_package_at`.
`Factor_Source_Observation_Investigation` supplies seven concrete subjects:
the actual source, a changed interface, removed clauses, an extra definition,
a different clause at the same source site, its corresponding actual source,
and an absent source. Proved functional subject maps connect every table index
to its actual program, environment and observation operation.

The existing investigation computes all profiles, pair losses, conflicts,
repairs and revisions. Starting from the separate domain, interface and clause
observations, it withdraws all three and selects the whole-source observation.
Starting with no observations yields that same selection; starting with the
whole observation retains it. Each returned selection is passed directly back
to the investigation and has no residual pairs.

This comparison groups inputs by the truth of the source-reading condition.
The separate field profile also distinguishes rejected inputs from one
another. Its failure therefore does not show that the conjunction of complete
interface and clause equality is insufficient. The whole observation computes
exactly that conjunction on each recovered program; its source-reading
equivalence holds universally, beyond the seven investigation subjects.

`Factor_Finite_Native_Sources` applies the existing singleton selector to the
complete unique package readings. `Some P` is equivalent to the actual native
reading of that entire program. `None` is equivalent to the absence of any
native package at those inputs. Completeness applies to malformed environments
and missing selectors as well as successful readings.

`Factor_Finite_Source_Extensions.finite_extend_source_native` receives the
actual environment, selector and complete proposed target. It recovers its
source itself, checks target formation and complete agreement on every old
definition, then executes the existing mapped extension with the source's
original coordinates. Success establishes every premise of the reused
constructor. `finite_source_native_run.correct` supplies whole target meaning,
fixed old definition sites, injective target placement, original package
recovery, and preservation of every original artifact and outgoing binding.
The operation fails exactly when its source and target context fails.

The recipe retains 23 complete report records:

| Family | Reports | Scope |
|---|---:|---|
| Source inputs | 7 | Every actual environment, complete candidate program, full native reading, source condition and field observation. |
| Derived table | 1 | All observation rows and the complete comparison relation. |
| Investigations | 3 | All initial results, repairs, revisions and the results of investigating each returned selection. |
| Extensions | 12 | Six complete attempts per actual source, including every target, source check, coordinate map, returned environment and original and target reading. |

The first eight extension sources are actual previously constructed packages:
the original equality source, an added empty clause family, self recursion,
peer recursion, a seeded peer cycle, whole and anchored literals, and both
complete material operands. Further sources contain the variable clause, an
empty package, no package, and an unused malformed artifact. Each source is
read again by every extension attempt.

The six proposals retain the source, add a conjunction over all its actual
definitions, change its interfaces, remove its clauses, cite an absent callee,
or introduce malformed syntax. There are 22 successful constructions and 50
rejections. Interface replacement and clause removal change no rows on the
empty source and are accepted there. No attempt with an absent or malformed
source succeeds. Material operands remain rule-application obligations;
successful package construction does not assert their satisfaction.
